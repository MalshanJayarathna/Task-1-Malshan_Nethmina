# 📌 Project Overview

This project was developed as part of the DecodeLabs Artificial Intelligence Internship — Project 1.

The objective of this project is to create a Rule-Based AI Chatbot capable of interacting with users using predefined rules and decision-making logic.

The chatbot can:

- Handle greetings
- Answer AI-related questions
- Respond to predefined commands
- Handle unknown inputs using fallback responses
- Exit safely using exit commands

---

# 🎯 Project Objectives

✅ Build a rule-based chatbot  
✅ Implement control flow logic  
✅ Use dictionary-based responses  
✅ Handle greetings and exit commands  
✅ Demonstrate foundational AI concepts  

---

# 🧠 AI Concepts Used

| Concept | Description |
|---|---|
| Rule-Based AI | Uses predefined logic instead of learning |
| IPO Model | Input → Process → Output |
| Control Flow | Program execution using conditions |
| Dictionary Knowledge Base | Stores chatbot responses |
| Input Sanitization | Cleans user input |
| Fallback Response | Handles unknown questions |
| Continuous Loop | Keeps chatbot running |
